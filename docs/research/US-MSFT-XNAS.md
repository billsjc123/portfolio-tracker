# 微软：AI 增长已经兑现，下一关是资本回报

## 一句话判断

微软把企业办公、身份安全、开发工具、数据库和云基础设施装进同一技术栈，是少数能同时从 AI 算力和 AI 应用收费的公司。2026 财年收入 3,318.39 亿美元、营业利润 1,552.37 亿美元，Azure 全年增长 41%，基本面仍强；但 2026 年 9 月 23 日 504.11 美元的收盘价已经高于模型的基准价值 366 美元和温和改善价值 440 美元，接近需要 AI 高增长与高资本回报同时兑现的强改善路径 572 美元。现有仓位应关注兑现而非追涨；新增资金在当前价格缺少预测误差缓冲。

## 公司做什么

微软向企业和个人出售云计算、办公与协作软件、操作系统、安全、开发工具、商业应用、搜索广告、游戏和设备。Microsoft 365 按用户收费，Azure 按使用量和合同收费，Dynamics、LinkedIn、安全及行业云扩展每个企业客户的使用范围；Windows、Xbox 和搜索连接消费者与开发者。它的优势不在某一个单品，而在身份、数据、开发、办公和云被同一企业反复采购。

AI 让微软同时扮演三种角色：建设数据中心并出租算力，通过 Azure AI、GitHub 和模型服务帮助客户开发应用，再把 Copilot 嵌入 Microsoft 365、Dynamics、安全和 Windows 收取席位或使用费。前两层资本密集，第三层更接近高毛利软件。估值的关键不是“微软有没有 AI”，而是高资本投入能否转化为足够的云消耗和应用收入。

### 产销链分析

价值链是：**芯片、电力与土地 → 数据中心和网络 → Azure 计算、存储、数据库及模型服务 → GitHub 与开发工具 → Microsoft 365、Dynamics 和安全应用 → 企业用户和消费者 → 合同续费与用量增长。** 上游包括英伟达、AMD、自研 Maia、服务器、网络、能源和建设供应商；微软承担建设、软件平台、销售和合规；下游企业通过订阅、用量合同和多年承诺购买服务。

传统软件把研发一次、复制多次，边际成本低；AI 云需要先购买 GPU、建设机房并持续付电力与运维。微软既有 6,780 亿美元商业剩余履约义务，也有数据中心租赁、采购和建设承诺。订单提供收入能见度，却不自动保证资本回报：客户何时部署、合同期限、OpenAI 相关承诺和每美元算力的毛利都重要。

## 业务拆解

[FY2026 财报](https://www.microsoft.com/en-us/investor/earnings/fy-2026-q4/press-release-webcast)披露三大分部。分部营业利润含公司分配成本，适合看相对经济性，但不能把它们当作独立公司的自由现金流。

- **生产力与业务流程**：收入 1,399.96 亿美元、增长约 16%，营业利润 838.79 亿美元，对应约 59.9% 分部营业利润率。包括 Microsoft 365、Teams、Copilot、LinkedIn、Dynamics 和部分行业应用。增长来自席位、E5/E7 等高阶套餐、Copilot 及使用量；Q4 Microsoft 365 商业云报告增长 14%，调整可比口径为 16%，付费 Copilot 席位超过 3,000 万。
- **智能云**：收入 1,377.91 亿美元、增长约 30%，营业利润 569.72 亿美元，利润率约 41.3%。包括 Azure、服务器产品和企业支持。Azure 全年增长 41%、Q4 增长 43%；成本也因 AI 基础设施快速上升，分部毛利率承压。
- **更多个人计算**：收入 540.52 亿美元、下降 1%，营业利润 143.86 亿美元，利润率约 26.6%。包括 Windows、设备、Xbox 和搜索广告。Q4 Xbox 内容与服务下降 10%，Windows OEM 与设备下降 7%，搜索广告不含流量成本增长 10%。它不是当前主要增长源，但维持分发、开发者和消费者入口。

FY2027 第一季度公司指引收入 898.5 亿至 909.5 亿美元，同比增长约 16%—17%；全年只给出收入和营业利润双位数增长、营业利润率下降不到 1 个百分点以及资本开支继续增长的方向性指引。模型的 FY2027 收入 3,816.15 亿美元、增长 15% 是分析假设，不是管理层给出的全年数字。

## 行业与竞争

云基础设施竞争围绕算力容量、芯片效率、开发工具、数据库、全球覆盖和企业销售。AWS 规模与基础设施生态强，Google 在数据、AI 模型和 TPU 上有优势，Oracle 在数据库和特定 AI 集群增长迅速；微软的差异是把 Azure 与企业身份、Office、GitHub、Windows 和销售关系捆在一起。客户多云策略和价格谈判会限制任何一家永久独占。

企业应用层同样有替代：Google Workspace 竞争办公协作，Salesforce 和 ServiceNow 竞争 CRM 与工作流，CrowdStrike、Palo Alto 等竞争安全，Zoom 和 Slack 竞争通信。Copilot 的分发优势明显，但“已经装进产品”不等于用户愿意持续支付高价；席位增长、活跃使用、续约和单位算力成本才是验证。

### 同业对比

| 参考公司 | 主要竞争面 | 微软相对优势 | 微软需要证明的部分 |
|---|---|---|---|
| Amazon AWS | 云基础设施、模型与企业平台 | 企业软件关系、混合云、开发与办公联动 | Azure 高增速能否在巨额资本投入下维持毛利与回报 |
| Google Cloud / Workspace | 云、TPU、模型、办公和广告 | 企业席位、身份、安全及渠道更完整 | Google 自研芯片和模型可能降低成本并提高竞争压力 |
| Oracle Cloud | 数据库与 AI 集群 | 服务范围更广、开发生态和全球企业覆盖更强 | 大型 AI 训练集群可能更重视价格、供电和可用容量 |
| Salesforce / ServiceNow | CRM、工作流及 AI 代理 | 可结合 Office、Teams、Azure 和身份数据 | Copilot 是否真正改善流程，而非只增加软件预算 |
| Apple / Sony / Nintendo | 设备、应用分发和游戏 | Windows 装机、订阅与云基础设施 | 消费者业务增长弱，Xbox 内容投入回报仍需改善 |

不能用纯软件公司的倍数给整个微软估值，也不能用数据中心公用事业的回报率给 Microsoft 365 估值。统一 DCF 的意义，是用集团利润率和增量资本回报把两种经济性重新合并。

## 管理层与资本配置

Satya Nadella 把微软从许可证公司转为云平台，并通过 GitHub、LinkedIn、Activision Blizzard 及 OpenAI 合作扩展生态，历史执行记录强。当前最重要的资本配置已经从收购转向 AI 基础设施。FY2026 新增 88 个数据中心，Q4 资本开支约 410 亿美元，其中约三分之二为寿命较短的 CPU 与 GPU；FY2027 资本开支仍预计增长。

管理层从 FY2027 起把数据中心和办公建筑估计使用寿命从 15 年延长至 25 年，并预计部分未来租赁从融资租赁转为经营租赁。公司称对 FY2027 营业利润的好处很小，但这会改变资本开支和租赁的呈现方式。研究上不能因为会计分类降低“资本开支”就认定经济投入下降，也不能只比较折旧利润率。

FY2026 公司回购 167 亿美元、宣告股息 270 亿美元。稀释股数 74.53 亿股，高于基本股数，模型保留股份支付费用，不为回购预先增加价值。OpenAI 和 Anthropic 等投资产生的公允价值收益波动较大，属于资本配置结果，不应替代 Azure、Microsoft 365 和应用本身的营业利润验证。

## 财务质量

[FY2026 10-K](https://www.sec.gov/Archives/edgar/data/789019/000119312526323660/msft-20260630.htm)披露收入 3,318.39 亿美元、增长 18%，营业利润 1,552.37 亿美元、增长 21%，经营现金流 1,829.35 亿美元。GAAP 净利润 1,337.49 亿美元包含 OpenAI 投资净收益带来的约 49.63 亿美元税后影响；排除后调整净利润为 1,287.86 亿美元，更接近核心盈利。

经营现金流增长很强，但数据中心投入同样加速：物业设备新增额较上年增加约 514 亿美元，期末物业设备净额从 2,049.66 亿升至 3,130.76 亿美元；Q4 现金支付物业设备 358 亿美元。公司还披露 278 亿美元服务器部件采购相关应收、113 亿美元受限投资、346 亿美元建设承诺，以及大量租赁与采购承诺。FY2026 经营现金流减现金资本开支会被应付设备款和租赁分类影响，因此估值从税后营业利润重建经济再投资。

期末现金及短期投资 768.43 亿美元，债务本金约 461.36 亿美元，模型采用净现金 307.07 亿美元；股权和其他投资不单独加入价值桥。商业剩余履约义务 6,780 亿美元、增长 84%，但包含大型 OpenAI 合同且平均期限约 2.3 年；排除 OpenAI 后增长约 25%，更适合判断广泛客户需求。

## 市场在定价什么

504.11 美元对应约 3.76 万亿美元股权价值，也相当于 FY2026 调整后每股收益 17.28 美元的约 29.2 倍。倍数不算离谱的前提是 FY2027 后仍保持十几%的增长，并让 AI 基础设施从资本消耗转为高回报现金流。

本模型基准价值 366 美元、温和改善价值 440 美元，当前价格比两者分别高约 38% 和 14%；只有接近强改善路径，价值才超过现价。换言之，市场不仅在定价 Azure 继续增长，也在定价 Copilot 和安全提高每客户收入、云毛利压力可控、增量资本回报长期显著高于 9.5% 要求回报。任何一项单独兑现都不够。

### 核心投资逻辑

**短期验证：** FY2027 第一季度收入能否达到 898.5 亿—909.5 亿美元，公司全年收入与营业利润是否继续双位数增长，营业利润率下降是否控制在 1 个百分点以内。Azure 增长和 Microsoft Cloud 毛利率必须联合观察。

**长期价值创造：** Azure 把新增数据中心容量转成高利用率的云消耗，Microsoft 365、GitHub、Dynamics 和安全再把模型能力变成席位与使用费；同一客户在身份、数据、开发和应用之间迁移成本提升。Base 假设长期营业利润率约 45%、稳定资本回报率 25%，并不保守。

**市场可能正确的理由：** 商业剩余履约义务、Azure 供给约束、Copilot 付费席位和企业分发说明需求真实；微软有能力把基础设施和应用收入同时收入囊中。如果 AI 代理成为企业主要界面，微软可能获得比传统云更大的钱包份额。

**市场可能过度乐观的理由：** 云客户和 OpenAI 具备议价力，GPU、电力与折旧推高成本；Copilot 的付费席位仍相对 Microsoft 365 安装基础有限，竞争模型和开源软件可能压低价格。收入增长若依赖越来越重的资本，利润增长不等于每股价值增长。

## 估值与操作

主方法是十年企业自由现金流 DCF。FY2027 分析锚为收入 3,816.15 亿美元、营业利润率 46%、税率 20%；要求回报统一为 9.5%，稀释股数 74.53 亿股，净现金 307.07 亿美元。公司只给双位数全年增长方向，因此 15% 收入增速是模型选择，不是管理层保证。

自由现金流等于税后营业利润减经济再投资；经济再投资按下一年新增税后营业利润除以增量资本回报率计算。这样既不会把所有 GPU 采购永久资本化，也不会因为租赁分类或延长折旧年限低估真实投入。稳定期再投资率等于永续增长率除以稳定资本回报率。

| 路径 | 经营假设 | 资本效率与终值 | 价值/股 | 当前价含义 |
|---|---|---|---:|---|
| 受损 | 外推收入增长 8% 后降至 3%，营业利润率由 42% 降至 40% | 增量资本回报降至 15%，永续增长 2% | **228 美元** | AI 利用率不足且云成本侵蚀传统软件经济性 |
| 谨慎 | 收入增长 12% 后降至 3%，利润率稳定在约 43% | 增量资本回报降至 20%，永续增长 2.5% | **288 美元** | 云和办公仍成长，但 AI 变现慢于基础设施投入 |
| 基准 | 收入增长 15%、13%、11% 后逐步降至 3.5%，利润率约 45% | 增量资本回报由 32% 降至 25%，永续增长 3% | **366 美元** | Azure、Copilot 与安全兑现，规模抵消部分资本压力 |
| 温和改善 | 收入增长 18% 后逐步降至 4%，利润率约 47% | 增量资本回报由 40% 降至 30%，永续增长 3% | **440 美元** | 云份额和应用 ARPU 同时提升，AI 产能保持高利用率 |
| 强改善 | 收入增长 22% 后仍长期较快，利润率接近 49% | 增量资本回报由 50% 降至 35%，永续增长 3.5% | **572 美元** | 微软成为企业 AI 控制层，并保留异常强的定价与资本效率 |

**当前 504.11 美元已经要求接近强改善的证据。** 对已有仓位，操作含义是持有但不把短期 Azure 超预期自动外推十年，并在 440 美元以上重点复核资本回报；对新增资金，366 美元附近才回到 Base，约 293 美元以下才满足相对 Base 约 20% 的模型折价。价格触发只表示重新研究，不是机械买卖；如果经营路径恶化，模型价值也会随之下修。

## 反方与风险

最强反论点是微软利用现有企业分发优势取得 AI 收入，却必须把越来越多现金投入 GPU、土地、电力和长期租赁；竞争让算力价格下降，应用层又未形成足够高的增量付费，最终收入增长但自由现金流和资本回报下降。OpenAI 既是合作伙伴、重要合同方，也可能成为议价强、融资依赖高的集中风险。

监管可能限制捆绑和收购，网络安全事故会伤害信任，AWS、Google、自研芯片和开源模型会压低云与模型服务价格，Xbox 和硬件仍可能拖累。估值也有模型风险：9.5% 要求回报不是精确资本成本，FY2027 收入是分析估计，长期 45% Base 利润率和 25% 稳定资本回报已经很高。当前价格没有为这些误差提供宽缓冲。

## 观察清单

- **FY2027 收入与利润**：Q1 指引 898.5 亿—909.5 亿美元；全年收入和营业利润双位数增长、营业利润率下降不到 1 个百分点。若公司下调其中两项，重算 FY2027 锚，而不是沿用 366 美元 Base。
- **Azure 与云毛利率**：Q4 Azure 增长 43%，Microsoft Cloud 毛利率 65%。增长保持高位但毛利率持续下行，说明资本和使用成本吃掉规模收益；两者需同看。
- **资本开支与利用率**：Q4 总资本开支约 410 亿美元，FY2027 仍预计增长。每季看新增容量、供给约束、现金资本开支、融资与经营租赁以及管理层对利用率的描述；会计分类变化不能算经济改善。
- **Copilot 变现**：Microsoft 365 Copilot 付费席位超过 3,000 万，M365 商业席位增长 6%。看净新增、续约、ARPU 和使用量；若席位只在折扣或捆绑下增长，降低应用层利润假设。
- **商业 RPO 质量**：商业 RPO 6,780 亿美元、含 OpenAI 增长 84%，排除 OpenAI 增长约 25%，约 30% 未来 12 个月确认。持续分开观察广泛客户与前沿模型公司合同，避免把集中大单当成普遍需求。
- **现金与资本回报**：FY2026 经营现金流 1,829.35 亿美元，但物业设备和供应链资金占用大幅增加。每半年用税后营业利润、实际现金投入和租赁承诺重算增量资本回报；低于 25% 且无改善时，Base 需要下修。
- **股权投资与稀释**：FY2026 OpenAI 投资收益使净利润增加约 49.63 亿美元，稀释股数 74.53 亿股。核心估值排除投资波动；股份支付和回购应按净稀释验证。

## 最近变化

- **2026-07-29｜FY2026 全年及 Q4 财报**：[公司披露 FY2026 收入增长 18%、营业利润增长 21%，Azure 全年增长 41%](https://www.microsoft.com/en-us/investor/earnings/fy-2026-q4/press-release-webcast)；Q4 收入 900.07 亿美元，Azure 增长 43%，商业 RPO 达 6,780 亿美元。**影响**：云和企业应用需求继续加速，但 Microsoft Cloud 毛利率受 AI 基础设施和使用量影响降至 65%。**研究处理**：把 FY2026 实际数据设为模型起点，剔除 OpenAI 投资收益，不因单季 Azure 超预期提高长期利润率。
- **2026-07-29｜FY2027 指引与会计估计变更**：[管理层预计 FY2027 收入和营业利润继续双位数增长、营业利润率下降不到 1 个百分点、资本开支同比增长](https://www.microsoft.com/en-us/investor/events/fy-2026/earnings-fy-2026-q4)，并将数据中心和办公建筑估计使用寿命从 15 年延长至 25 年。**影响**：增长能见度强，但自由现金流仍受高投入约束，资本开支和租赁分类的可比性下降。**研究处理**：FY2027 采用独立 15% 收入增速和 46% 利润率锚，估值改用经济再投资并把利用率和资本回报列为核心路标。
