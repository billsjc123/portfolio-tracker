# 亚马逊：云业务兑现增长，但巨额投资何时变成股东现金？

## 一句话判断

亚马逊是零售、第三方商家服务、广告、会员订阅和云计算组成的复合平台。2026 年第二季度，AWS 收入增长 37%、营业利润增长 64%，北美零售与广告也在增厚利润；但过去十二个月经营现金流 1,614 亿美元，自由现金流反而为**负 76 亿美元**，因为 AI 与基础设施投资正在提前消耗现金。[公司二季度业绩](https://ir.aboutamazon.com/news-release/news-release-details/2026/Amazon-com-Announces-Second-Quarter-Results/default.aspx?mode=light)

截至 2026 年 9 月 24 日收盘，股价 **249.38 美元**。以 9.5% 要求回报率、未来十年营业利润和增量资本回报的分析假设计算，受损、谨慎、基准、温和改善和强改善路径分别约为 **93、119、154、191、237 美元/股**。模型对现金再投资和折现率极其敏感，不能把这些数字当作已验证目标价；但现价也不能仅凭“低于历史平均市盈率”判定便宜。当前研究立场是**纳入观察仓，等下一次财报验证 AWS 利润增长与资本开支的现金回收，不因 META 上涨就自动换入**。

## 公司做什么

消费者在亚马逊网站和应用购买商品；亚马逊可能自己采购并销售商品，也可能让第三方商家出售。自营收入按商品售价确认，商家服务则通过佣金、仓储、配送和其他服务收费。Prime 会员用年费或月费换取配送、视频等权益，提升购买频率和留存。商家和品牌还向亚马逊购买站内广告，以便在高购买意图的页面获取流量。

AWS（亚马逊云科技）向企业、初创公司、政府和开发者出租计算、存储、数据库与 AI 服务。客户按使用量、协议和服务层级付款；需求增加会先带来数据中心、服务器、芯片、电力和网络投入，之后才可能产生多年收入。零售、广告和 AWS 的客户与资产经济性不同，不应给全公司一个简单的“电商”或“AI”倍数。

### 产销链分析

**零售链**是品牌与商家供货 → 亚马逊提供网站流量、仓储和配送 → 消费者下单 → 商品收入、商家服务费、广告费和会员费入账。配送密度、库存周转和广告变现提高时，更多订单可以转成更高利润；若物流成本和促销上升快于收费，收入增长未必增厚现金。第三方商品成交额不是亚马逊收入，只有其佣金和服务费进入报表。

**云计算链**是芯片、服务器、能源、建筑与软件研发 → AWS 数据中心和平台 → 客户部署应用或训练、运行模型 → 使用费与长期合同收入。AWS 的规模和生态可以提高利用率与客户迁移成本，但客户只有从软件、广告或生产率中赚到钱，才能长期覆盖云费用。数据中心建成后的闲置、折旧和融资成本会比需求短缺更早伤害股东回报。[2026 年二季度 10-Q](https://www.sec.gov/Archives/edgar/data/1018724/000101872426000026/amzn-20260630.htm)

## 行业与竞争

零售的竞争集中在价格、选品、交付速度和商家获取用户的成本。亚马逊的规模使商品、商家、流量、广告和物流形成循环，但规模也要求持续投资仓库、配送与会员权益。广告的优势来自用户接近购买决策的场景；弱点是消费者体验不能被过多商业化侵蚀。

云计算的竞争不只在服务器价格，还在芯片、开发工具、数据平台、安全、模型能力和全球数据中心容量。AWS 第二季度 37% 增长显示需求强劲，却不能直接证明新投入资本已赚回成本：上半年 AWS 资产净增加约 **901 亿美元**，而上半年 AWS 营业利润约 **308 亿美元**。前者不是完整现金资本开支口径，但足以说明未来折旧与利用率的重要性。[Amazon 10-Q](https://www.sec.gov/Archives/edgar/data/1018724/000101872426000026/amzn-20260630.htm)

## 管理层与资本配置

亚马逊长期倾向于把现金重新投入物流、云基础设施和新业务，而非发放现金股息。这个策略只有在新增投资的回报高于资金成本时才为股东创造价值。2026 年上半年，公司长期债务从 2025 年末约 656 亿美元增至约 **1,289 亿美元**；同期现金与可交易证券约 **1,230 亿美元**。资产负债表尚非单一的“现金耗尽”故事，但扩张已更依赖外部融资。[二季度 10-Q](https://www.sec.gov/Archives/edgar/data/1018724/000101872426000026/amzn-20260630.htm)

管理层在 2026 年第二季度披露 AWS 高速增长和 AI 产品需求，这是需求验证，不等于资本回报验证。Anthropic 等股权投资的重估收益进入 GAAP 净利润，不能当成 AWS 或零售的可持续经营盈利。公司的优势是敢于在技术转型期预先建产能；最强反方是产能建得过快、客户付费或利用率跟不上。

## 财务质量

2026 年第二季度收入 **2,006.06 亿美元、同比增长 20%**，营业利润 **274.61 亿美元、同比增长 43%**。过去十二个月经营现金流 **1,614 亿美元**，但公司定义的自由现金流为**负 76 亿美元**，而上年同期为正 182 亿美元，主要因为 AI 相关固定资产购买大增。经营利润与所有者现金出现明显分叉。[公司业绩](https://ir.aboutamazon.com/news-release/news-release-details/2026/Amazon-com-Announces-Second-Quarter-Results/default.aspx?mode=light)

第二季度 GAAP 净利润 **626.47 亿美元**含 **534.15 亿美元非经营收益**，主要来自 Anthropic 等投资。因此“249 美元 ÷ GAAP 每股收益”得出的市盈率不能说明核心业务便宜。我们的经营模型从营业利润及税后经营利润起步，保留已计入营业费用的股份支付，不预支未来回购收益；模型也**没有**给未实现投资收益单独加值。另一个误差来源是，模型按增量资本回报反推未来再投资，可能与实际建设现金支出的时间差很大。[二季度 10-Q](https://www.sec.gov/Archives/edgar/data/1018724/000101872426000026/amzn-20260630.htm)

## 市场在定价什么

249.38 美元对应约 **2.69 万亿美元股权市值**。扣除现金及可交易证券、加上长期债务后，企业价值约 2.695 万亿美元；相对于过去十二个月 **937 亿美元**营业利润，约 **28.8 倍企业价值/营业利润**。这不是明显只按成熟零售定价：市场显然预期 AWS 的增长与广告/商家服务利润可以继续扩大，并认为当前 AI 投入未来会带来足够高的回报。[股价](https://stockanalysis.com/stocks/amzn/history/) · [10-Q](https://www.sec.gov/Archives/edgar/data/1018724/000101872426000026/amzn-20260630.htm)

长桥在 2026 年 9 月 25 日查询到的市场聚合预期为：2026 年第三季度收入约 **2,021 亿美元**、营业利润约 **259 亿美元**，分别在公司收入和利润指引的高端附近。这是市场观点，不是已实现业绩；接口未给出该两项预测的分析师覆盖数或完整建模依据，因此不能直接拿来校准十年现金流。聚合目标价同样不是内在价值。

### 核心投资逻辑

**短期要验证的不是 AWS 收入是否仍增长，而是 37% 高增速能否继续转成营业利润，同时资本开支增速是否开始被经营现金流追上。** 2026 年第三季度公司指引收入 **1,970—2,020 亿美元**、营业利润 **225—265 亿美元**；这是下一次同口径校验点，不是我们的十年 Base。[公司指引](https://ir.aboutamazon.com/news-release/news-release-details/2026/Amazon-com-Announces-Second-Quarter-Results/default.aspx?mode=light)

**长期价值创造**来自三个同时成立的条件：AWS 租出的计算资源能保持较高利用率与合理价格；自研芯片和规模经济降低单位成本；零售的第三方服务、广告和会员提高每单利润。市场可能正确：若 AI 工作负载持续扩大，当前资本开支只是新利润池的前置建设，我们的回报率假设就过低。我们可能正确：若建设周期变长或竞争压低租价，收入增长仍会伴随低自由现金流和更重的融资负担。

## 估值与操作

**主方法是按 AWS 与零售服务两条利润路径建立的十年经济现金流模型，PE、PEG、PS 只用于交叉验证市场定价。** 市销率不反映 AWS 与零售的利润率差异；市盈率易受投资重估扭曲；PEG 把利润增长视为“免费”，不扣为了增长投入的资本，所以三者都不宜单独决定买价。

共同起点是分析估计的 **2026 全年 AWS 营业利润 650 亿美元、北美加国际 400 亿美元**，合计 1,050 亿美元；它不是管理层指引。计算桥为：2026 上半年 AWS 已实现 307.82 亿美元，所以上半年之后仍需约 342.18 亿美元；零售两分部上半年已实现 205.31 亿美元，后半年仍需约 194.69 亿美元。合计后半年约 536.87 亿美元，包含公司给出的第三季度 225—265 亿美元利润指引和我们对第四季度的余额估计。以 **20% 分析税率、9.5% 要求回报率、109.03 亿稀释股、3% 永续增长**建模，税后营业利润减去“新增税后营业利润 ÷ 增量资本回报率”作为现金流；稳定期再投资率等于 **3% ÷ 稳定资本回报率**。[模型财务锚点：10-Q](https://www.sec.gov/Archives/edgar/data/1018724/000101872426000026/amzn-20260630.htm)

| 经营路径 | 2027 年利润增长推导与后续约束 | 新投入资本回报假设 | 条件价值/股 |
|---|---|---|---:|
| 受损 | AWS 从 650 亿增长 10% 至 715 亿；零售从 400 亿增长 3% 至 412 亿。AI 需求迅速放缓，十年后增长降至约 3%。 | 首年 7%，稳定期 13%；低利用率吞噬现金 | **约 93 美元** |
| 谨慎 | AWS 首年增长 18% 至 767 亿；零售增长 6% 至 424 亿。云仍增长，但扩建回收慢于利润表现。 | 首年 9%，稳定期 17% | **约 119 美元** |
| 基准 | AWS 首年增长 25% 至 812.5 亿；零售增长 10% 至 440 亿。AWS 从第二季度 37% 收入增长和 39.4% 利润率的高位逐渐放缓；广告与商家服务支持零售利润。 | 首年 12%，随后随产能利用率改善，稳定期 20% | **约 154 美元** |
| 温和改善 | AWS 首年增长 30%，零售增长 12%；云产品和自研芯片均改善回报。 | 首年 16%，稳定期 24% | **约 191 美元** |
| 强改善 | AWS 首年增长 35%，零售增长 14%，此后多年维持较高利润增速。 | 首年 20%，稳定期 27% | **约 237 美元** |

上述增速与资本回报**都是分析情景，不是公司披露**。三条核心路径的边界很明确：悲观不是机械打折，而是 AI 建设过剩；谨慎是需求在、回款慢；基准要求高需求与利用率改善同时成立。公司没有披露 AWS AI 投入的独立增量资本回报，因此回报率的具体百分比尚不能被外部直接验证。约 **73%** 的基准价值来自十年后的终值；9.5% 回报要求下 Base 约 154 美元，若改为 **8%** 则约 **214 美元**，改为 **11%** 则约 **117 美元**。这个敏感度要求我们把估值当作待验证条件，而非精确目标。

现价高于这组**条件情景**的强改善价值，但这不是确定的高估结论：市场可能计入未单列的投资资产、采用更低的要求回报率，或预期更高的长期云资本回报。观察仓阶段**不设置机械买入价**；只有实际财报持续显示“营业利润增长 + 现金投入收敛 + 股数未明显稀释”，才考虑上调经营路径。价格单独下跌不能修复模型的不确定性。

## 反方与风险

最强正面反论点是：2026 年的资本投入像早期 AWS 一样，先建容量后多年收租；若新客户合同和自研芯片把利用率迅速推高，当前现金流低谷反而是扩大护城河的成本。模型未给 Anthropic 等投资资产单独估值，也可能漏掉可兑现价值。

最强负面风险则是“收入好、现金差”长期化。2026 年上半年 AWS 资产净增加约 901 亿美元，未来若折旧、能源和芯片更新快于客户收入，模型的 12% 起步、20% 稳定增量资本回报会偏乐观。北美利润率 7.9%、国际 4.1% 也可能因配送、竞争或广告负担回落。债务增加会把经营预测错误更直接地传到每股价值。未实现投资收益和不透明的资产估值还会让 GAAP 市盈率给出错误安全感。[10-Q](https://www.sec.gov/Archives/edgar/data/1018724/000101872426000026/amzn-20260630.htm)

## 观察清单

- **AWS 增长是否转成利润？** 当前锚点为 2026Q2 收入 422.32 亿美元、同比 +37%，营业利润 166.21 亿、利润率 39.4%。基准要求 2027 年 AWS 营业利润从估计的 2026 年 650 亿增长约 25%。下一季先与公司披露的 AWS 收入、利润和利润率同口径比较；若收入增长而利润率持续下滑，复核算力价格、折旧和基准利润路径，不因收入超预期自动上调估值。
- **资本开支何时形成股东现金？** 当前过去十二个月经营现金流 1,614 亿美元，自由现金流负 76 亿美元；上半年 AWS 资产净增加约 901 亿美元。基准估计 2027 年现金流仍可能为负，之后随增量资本回报改善转正。每季看公司定义的经营现金流、固定资产净购买、自由现金流及 AWS 资产增加；若利润增长持续但现金缺口扩大，降低增量资本回报路径并重估。
- **零售的高利润收入能否覆盖履约？** 当前 Q2 广告收入 198.09 亿、第三方商家服务 467.80 亿；北美营业利润率 7.9%、国际 4.1%。基准要求两大零售分部 2027 年营业利润由估计的 400 亿增长约 10%。每季若广告/商家收入放缓而配送与促销成本上升，先下修零售利润，不单凭总商品销量判断。
- **融资和每股价值是否恶化？** 2026Q2 现金及可交易证券约 1,230 亿美元、长期债务约 1,289 亿美元，季度稀释股约 109.03 亿。每季看债务、利息、股权激励和稀释股；若融资增加却未提高每股经营现金，修正资产桥和每股估值。
- **下一次财报核验。** 公司对 2026Q3 给出收入 1,970—2,020 亿美元、营业利润 225—265 亿美元的区间。财报日期以公司投资者关系公告为准；先检验指引，再检查 AWS 与零售分部及现金流，不以一项“超预期”替代整条价值链。

## 最近变化

- **2026-07-30｜第二季度财报与第三季度指引：** [公司披露](https://ir.aboutamazon.com/news-release/news-release-details/2026/Amazon-com-Announces-Second-Quarter-Results/default.aspx?mode=light) AWS 收入增长 37%、营业利润达 166.21 亿美元，同时过去十二个月自由现金流降至负 76 亿美元，并给出第三季度营业利润 225—265 亿美元指引。**研究影响：** 云需求和利润已有现实验证，但资本投入回收仍未验证。**研究处理：** 以分部营业利润而非含投资重估的净利润建模，观察清单同时跟踪 AWS 利润、资本开支和每股融资。
